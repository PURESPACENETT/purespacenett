# Supabase migration workflow

The active, versioned SQL history is `supabase/migrations/` at the repository root. It targets the `dgppmlkpvmvjkhsghtji` Supabase project used by both the public site and CRM.

The former CRM Drizzle and CRM-local Supabase migration files are retained under `apps/crm/archive/` for audit and recovery. They are not deployment inputs. Drizzle generation dependencies and its active config were removed so a second numbered SQL history cannot be generated by accident.

The CRM Edge Function source remains under `apps/crm/supabase/functions/`. The root migration replay CI starts a disposable local Supabase stack and replays `supabase/migrations/`; it does not connect to production. Never run a production migration push until the pending migration list has been reviewed against Supabase's applied migration ledger.

Production migration state was inspected separately during this change. No SQL migration was applied remotely.
